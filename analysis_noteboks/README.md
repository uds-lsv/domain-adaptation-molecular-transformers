# Analysis Folder

This folder contains the results from our different experiments and the benchmarking from random and Butina splitting in
[repearted_5_5_cv](repeated_5_5_CV) folder

The datasets for pre-training (i.e., GucaMol training set) and downstream (i.e., the ADME benchmark by Fang et. al., and AtraZeneca ChEMBL) 
can be found in [pretrain_and_downstream_datasets](pretrain_and_downstream_datasets)

The notebook [repeated_cv_performance_analysis.ipynb](repeated_cv_performance_analysis.ipynb) provides a walkthrough our analysis methods and figures while 
the notebook [data_analysis.ipynb](data_analysis.ipynb) provides a walkthrough our characterization of the pre-training 
and downstream datasets.
